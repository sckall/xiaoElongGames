# 《鳄龙咆哮》战斗判定与弹道算法

> 回答“弹道看着怪怪的，是否参考其他 FPS 算法优化”：参考成熟 FPS 的做法，
> **命中判定与视觉弹道分离**。本文记录当前实现与后续优化路线。

## 1. 成熟 FPS 的通行做法（参考）

| 游戏/引擎 | 判定方式 | 视觉弹道 |
|-----------|----------|----------|
| Counter-Strike | 服务端 **hitscan（射线）** + 后坐图案 + 延迟补偿 | 枪口闪光 + 极短 tracer |
| VALORANT | 服务端 hitscan（首发精准/后续散布）+ 每发独立散布 | 枪口到命中点瞬间细线 |
| Quake 系 | 部分 hitscan（LG/RG）+ 真实抛体（火箭/榴弹） | 抛体模型可见 |
| 守望先锋 | 部分 hitscan + 部分抛体 | 亮色抛体 |

结论：**步枪/狙击/手枪用 hitscan 是对的**；视觉上“怪”通常来自
tracer 起点在屏幕中心、没有枪口偏移、以及近战误用了子弹特效。

## 2. 当前实现（服务端权威，已修正）

- 服务端每发子弹：从 `eyeY` 出发，方向 = 视角 yaw/pitch + 武器散布；
  与掩体 AABB（slab 求交）和玩家胶囊（线段-胶囊）取最近命中；
  命中点高度 ≥ `headshotMinY` 判爆头；距离按 `falloffStart/End` 衰减。
- 客户端 tracer：**从枪口世界坐标出发**（Kenney GLB 枪模的实际枪口），
  指向服务端返回的命中点，0.12 秒淡出——判定与视觉分离。
- 匕首：锥形近战判定（距离/角度/遮挡），客户端挥砍动画 + 白色弧光，
  **不再产生子弹 tracer/枪口火光**。
- 开镜：FOV 平滑过渡 + `adsSpread` 收紧散布；狙击进入镜内视野。
- 后坐：`weapons.recoil` 只做视角上跳表现，服务端散布独立计算。

## 3. 下一步弹道优化路线

1. **延迟补偿（lag compensation）**：服务端按开火者视角回滚到其输入时刻判定
   （CS/Valorant 同款），公网高 ping 下公平性关键。
2. **弹道轨迹升级**：给步枪加 1-2 帧亮核+辉光；狙击 tracer 更细更亮；
   远程命中加“火花+烟尘”两段反馈。
3. **散布可视化**：准星随连续射击/移动动态扩散（当前准星为静态四段杠）。
4. **抛体武器**：诡雷/雷暴云改为可见抛物线抛体，粘附与爆炸表现更真实。
5. **受击方向指示器**：屏幕边缘按伤害来源方位泛红。

## 4. 相关调试

- 弹道/散布/后坐/爆头线全部在 `gameplay.json`，`?debug=1` 面板可实时调；
- `?debug=1` 勾选“显示玩家碰撞盒”可查看胶囊与掩体 AABB 是否和视觉一致；
- 命中事件在快照 `events` 中带命中点与伤害，`?debug=1` 左上角可观察网络漂移。
