# 出包魔法师桌游基本规则

## 游戏简介

- 《出包魔法师》中的“出包”是Trouble音译而来。一群见习魔法师聚在一起，大家不知道自己会什么魔法，随意施法，场面一度混乱，欢乐无穷。

- 每位玩家初始会拥有5张魔法卡牌和6生命，但每个人不知道自己有什么卡牌，只知道别人有什么卡牌。玩家要轮流施展魔法，从而猜测自己拥有什么魔法（大声喊出魔法的名字）（其他人会告诉你施法成功还是失败）。

## 游戏配置

《出包魔法师》包括36张魔法卡牌，卡牌有8种：
- 1张🐉古代巨龙：其他人扣除1-3生命
- 2张👻黑暗幽灵：其他人扣除1生命，你增加1生命
- 3张💕甜蜜的梦：你增加1-3生命
- 4张🦉猫头鹰：查看并获取一张秘密牌，本轮若你存活，每张秘密牌让你多加一分（下文会解释秘密牌）
- 5张⛈️闪电暴风雨：上家和下家扣除1生命
- 6张🌨️暴风雪：上家扣除1生命
- 7张🔥火球：下家扣除1生命
- 8张🧪魔法药水：你增加1生命
以上是施法成功的效果。如果施法失败，你会扣除1生命。但有个例外，🐉古代巨龙是威力巨大的魔法，如果施放失败，你要扣除1-3生命。上述涉及1-3生命的技能（🐉古代巨龙、💕甜蜜的梦），具体数值是由掷骰子决定的。

## 游戏准备

- 一局游戏会分很多轮，每轮结算一次积分。

- 在每一轮的开始每人有6生命（最大值也是6），洗混36张牌每人随机抽取5张魔法卡牌，不能看自己的牌，可以看其他玩家的牌

- 此外，还要取出一些牌作为“秘密牌”（避免后期太简单）：2人游戏有12张秘密牌，3人游戏有6张秘密牌，4、5人游戏有4张秘密牌

## 游戏流程

- 每一轮游戏，随机选一人开始，轮流操作。当前回合玩家需要大声喊出一种魔法的名字，如果他拥有该魔法，则打出该牌，执行魔法效果，随后他可以继续施法。下次施法有限制，不能施放比上种魔法更罕见（即总张数更小）的魔法。此外，他也可选择结束回合，轮到下一位玩家。如果他没有该魔法，那么他要扣1点生命，随后他必须结束回合，轮到下一位玩家。

- 每个玩家回合结束时，需要摸牌补齐到5张（如果剩余的牌摸完了，就不需要摸了）

- 如果某玩家在他的回合施放了他的所有魔法，那么本轮就结束了，他得3分，其他玩家死亡。如果某玩家在他的回合击败了其他任一玩家，那么本轮就结束了，他得3分，存活玩家得1分。如果某玩家在他的回合因用错魔法自杀了，那么本轮就结束了，其他玩家得1分。（注：🦉猫头鹰会导致额外加分，若成功施放🦉猫头鹰魔法，你需查看并获取一张秘密牌，本轮若你存活，每张秘密牌让你多加一分。注意秘密牌不是你的魔法，你无法施放秘密牌）

- 本轮结束后，若没有玩家达到8分，便开启下一轮，若有玩家到达8分，分数最高的玩家胜利。
