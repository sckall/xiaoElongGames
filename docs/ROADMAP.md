## 📍 阶段 2：Steam 上架准备

**目标**：把 Web 内核套进 Electron，外加 Steamworks 集成。

### 2a. Electron 外壳（2-3 周）
- 用 `electron-builder` 打包 Windows/macOS/Linux
- 主进程加载 `apps/web/dist`
- 启动器 UI：分辨率、画质、音效、服务器地址
- 自动更新（用 `electron-updater` + 自建更新源，或 Squirrel）

### 2b. Steamworks 集成（2-3 周）
- 接入 `steamworks.js`（TypeScript 友好）
- **鉴权层**：用 SteamID 作为 `playerId`（替代 UUID）
- **云存档**：`tm-settings`/`tm-tokens` 同步到 Steam RemoteStorage
- **成就**：定义 schema（出包魔法师 10 个 / 鳄龙咆哮 15 个）
- **Overlay**：F2 截图、F12 帧率显示等

### 2c. 联机改造（**决策点**）

**方案 A：保留 Socket.IO + Steam 鉴权（最小改动，推荐 MVP）**
- 服务器加一个 `/auth/steam` 端点
- 启动器用 Steam Ticket 兑换 session token
- 协议 `playerId` 改为 SteamID（string）
- **工时**：1 周
- **风险**：低
- **上限**：500-1000 同时在线（取决于服务器带宽）

**方案 B：Steam P2P（更大改动）**
- 主机当权威（房主）
- 客户端用 Steam Networking Sockets 直连
- 服务端只做「匹配 + 鉴权 + 房间列表」
- **工时**：3-4 周
- **风险**：中（NAT 穿透、主机掉线迁移）
- **上限**：理论无限

> **建议**：MVP 走方案 A，规模上来再迁移 P2P。

### 2d. Steam 商店页面（2 周）
- 5 张 Capsule 图（616x353、460x215、374x448、220x220、32x32）
- 主页大图、截图 ≥ 5 张、Steam Deck 截图
- 中文/英文双语商店描述
- 准备 30s + 60s 两段宣传视频
- 系统需求、年龄分级

### 2e. IARC 年龄分级（3 天）
- 填问卷（出包魔法师 = E，鳄龙咆哮 = E10+ 或 T）

**退出标准**：
- 通过 Steamworks 审核
- 上架 Steam 全球区（**不含中国大陆**）
- 首周愿望单 ≥ 1000

## 📍 阶段 3：商业化

**目标**：上线基础付费模型 + 数据驱动运营。

### 3a. 用户体系与数据持久化（3-4 周）
- 账号系统：游客 → Steam 登录（最低成本）
- PostgreSQL：用户、对局、订单、排行榜
- Redis：房间状态、会话、限流、ZSET 排行榜

### 3b. 商城系统（4-6 周）
- 虚拟币（宝石/钻石）
- 礼包：出包魔法师主题卡包、鳄龙咆哮英雄皮肤、武器涂装
- Steam 内购接入（Steam Wallet 结算）
- 礼包定价：$0.99 / $4.99 / $9.99 / $19.99 四档

### 3c. 通行证 / 赛季（4-8 周）
- 赛季时长 3 个月（出包魔法师 / 鳄龙咆哮分赛季）
- 通行证：免费 / 付费双轨（$9.99/季）
- 经验值来源：对局 / 任务 / 成就

### 3d. 排行榜 / 匹配（3-4 周）
- Redis ZSET：单英雄天梯、全球/地区榜
- 匹配：Elo 分 + 延迟优先

### 3e. 运营工具（2-3 周）
- 后台：账号查询、封号、对局回放、调参
- 客服：投诉处理、聊天过滤
- 数据看板：DAU/MAU/付费率/留存

**退出标准**：
- ARPPU ≥ $3
- 月流水 ≥ $5000
- 留存 D7 ≥ 15%

## 📍 阶段 4：长线运营 + 大陆区

**目标**：申请版号 + 大陆区上架 + 长线内容运营。

### 4a. 版号申请（启动即申请，耗时 12-18 个月）
- 找代理公司（30-80 万 RMB）
- 准备材料：游戏说明书、原创证明、运营公司资质
- **不可控周期**：12-18 个月，期间**继续海外运营**

### 4b. 新内容节奏
- **每 2 个月**：1 个英雄 / 1 套卡包 / 1 个地图（轮换）
- **每 3 个月**：赛季通行证
- **每 6 个月**：1 款新游戏（用现有平台架构快速接入）

### 4c. 创意工坊（Steam 审批慢，准备 6 个月）
- 出包魔法师：自定义卡池
- 鳄龙咆哮：自定义地图 / 武器 mod

### 4d. 电竞 / 观战
- 鳄龙咆哮：观战服务器（订阅模式）
- 集成 OBS / 直播平台
- 季度赛 / 邀请赛

**退出标准**：
- 大陆区上架（拿到版号后）
- 月流水 ≥ $50000
- 团队扩到 5-8 人

## 📍 阶段 5：扩展与跨平台

**目标**：从单平台扩展到多平台 + 多形态。

**关键任务**：
- **Switch 移植**：用 Electron → web → Switch 浏览器壳（类似 Itch.io 模式）；或重写为 Godot/Unity
- **手机端**：出包魔法师适配竖屏；鳄龙咆哮适配触屏（虚拟摇杆 + 陀螺仪瞄准）
- **AI 训练**：用对局数据训练 AI 模型
- **观战 / 直播平台接入**：Twitch / B 站 / 抖音

**退出标准**：
- 跨 3 平台
- 月活 ≥ 100 万
- 年流水 ≥ $1M
